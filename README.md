## 1 Подготовка

Распакуйте новый архив в отдельную папку. Откройте папку `schedule-devops-25`,
в которой находятся `build.py`, `schedule.json`, `README.md`, `src` и `tests`.
Не запускайте проект прямо внутри ZIP. В VS Code выберите File → Open Folder,
затем Terminal → New Terminal. В Windows можно открыть PowerShell в этой папке.

Проверьте установки:

```bash
python --version
git --version
```

Нужны Python 3.11+ и Git. Официальные сайты: https://www.python.org/downloads/
и https://git-scm.com/downloads. После установки откройте терминал заново.
Если Windows не находит `python`, замените его во всех командах на `py -3`.
В macOS/Linux при необходимости используйте `python3`.

## 2 Сборка и запуск

Выполняйте команды по одной из папки проекта:

```bash
python build.py
python -X utf8 dist/schedule.pyz
python -m unittest discover -s tests -v
```

Ожидается `Build OK: dist/schedule.pyz`, семь строк расписания,
затем `Ran 14 tests` и `OK` (время выполнения может отличаться).
Сначала нужна сборка: часть тестов проверяет собранный файл `dist/schedule.pyz`.
Ничего устанавливать через pip не нужно.

Выбор отдельного дня:

```bash
python -X utf8 dist/schedule.pyz --day Понедельник --group ИС
python -X utf8 dist/schedule.pyz --day Пятница --group ИС
python -X utf8 dist/schedule.pyz --day Суббота --group ИС
```

У последней строки субботы должен быть кабинет `310а` (буква «а» кириллическая).
Чтобы сделать локальный скриншот, разверните терминал и выполните полный вывод.
В Windows используйте Win+Shift+S, в macOS — Cmd+Shift+4.

## 3 Что проверяют тесты

14 тестов: точное совпадение семи записей JSON с независимым эталоном;
фильтрация реального расписания; сортировка; конфликт группы; конфликт кабинета;
соседние интервалы; параллельные занятия разных групп в разных кабинетах;
неверные поля; полный вывод приложения; понедельник; пятница; суббота с 310а;
пустая выборка; повреждённый JSON.

Тестовые конфликты и «ТЕСТОВАЯ ГРУППА» — искусственные данные для проверки
ошибок, они не записываются в schedule.json. Если расписание в будущем меняется,
обновите и независимый список EXPECTED в tests/test_schedule.py.
